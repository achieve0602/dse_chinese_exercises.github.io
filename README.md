# 文言研習室 (DSE 中文 12 篇範文練習工具)

這是一個幫 DSE 考生溫習 12 篇文言範文的單一網頁練習工具。不用安裝任何東西，也不用開帳號，直接用瀏覽器打開就能開始做題。

---

## 🎯 它能幫你做什麼？

### 1. 自由選擇練習範圍
- **篇章任選**：涵蓋 DSE 必考 12 篇範文（也可選「隨機篇章」混著練）。
- **3 種難度**：基礎（Lv 2–3）、進階（Lv 4–5）、拔尖（Lv 5**）。
- **2 種題型**：MC 選擇題、長答題（問答分析題）。

### 2. MC 選擇題：即時對答案與選項剖析
- 點選答案後會立刻顯示對錯與正解。
- 附帶**引文出處**和**詳細解釋**。
- 每個干擾選項（錯的選項）都會直接寫出**錯在哪裡**，幫你避開常見陷阱。

### 3. 長答題：本地模擬評分與失分診斷
- 提供答題框，附即時字數統計。
- 送出答案後，系統會比對預設的評分參考點（Rubric）：
  - 清楚列出每個得分點（拿了幾分／有沒有命中）。
  - 提供**標準參考答案**。
  - 診斷你漏答了哪些重點，並給出具體的補強建議。

### 4. 自動錯題簿
- 只要選擇題答錯，或長答題沒拿滿分，系統就會**自動存入錯題簿**。
- 隨時可以切換到錯題簿：
  - 展開查看原題目、你當時寫的答案、正解與完整解析。
  - 搞懂之後可以單題刪除，也可以一鍵清空。

### 5. 成績統計與進度保存
- 左側面板會自動統計：已做題數、答對題數、平均得分率。
- 顯示最近 4 筆練習紀錄。
- **全本地保存**：進度會直接存放在瀏覽器裡（LocalStorage），不用連網也不會把你的作答資料傳給別人。

## 💻 怎麼使用？

### 方法一：直接在電腦/手機開啟
1. 下載專案裡的 `index.html`。
2. 雙擊直接用任何瀏覽器（Chrome、Safari、Edge 等）打開就能用，離線也能做題。

### 方法二：放在網路上（GitHub Pages）
1. 把這個 Repo 推送到 GitHub。
2. 到 Repo 的 **Settings** -> **Pages**。
3. Source 選 **Deploy from a branch**，分支選 `main`（或 `master`），點儲存。
4. 等 1~2 分鐘就會生成一個網址，用手機或分享給同學隨時隨地都能刷題。
